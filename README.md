# 🍽️ Food Order System

A desktop-based Food Order System built using **Python (Tkinter)** and **PostgreSQL**.
This application allows users to browse hotels, view menus, add items to cart, and place orders.

---

## 🚀 Features

* 🔐 User Login Authentication
* 🏨 View Available Hotels
* 📋 View Menu Items
* 🛒 Add Items to Cart
* 💳 Order Placement
* 🗂️ Order Stored in Database

---

## 🛠️ Tech Stack

* Python (Tkinter)
* PostgreSQL
* psycopg2

---

## ⚙️ Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/hariharansuresh1971-dotcom/food-order-system.git
```

2. Install dependencies:

```bash
pip install psycopg2-binary
```

3. Setup PostgreSQL:

* Create database: `food_order`
* Create tables (users, hotels, menu, orders)

4. Update DB credentials in:

```bash
config/db_config.py
```

5. Run the project:

```bash
python main.py
```
